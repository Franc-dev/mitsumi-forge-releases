# Mitsumi Forge

Describe it. Forge builds it. A desktop app that plans, writes, runs and fixes real full-stack apps on your own computer, with a live preview as it works.

This repository hosts the Mitsumi Forge installers. The source code isn't published here.

## Download

Get the Windows installer from the [latest release](https://github.com/Franc-dev/mitsumi-forge-releases/releases/latest):

- **Mitsumi-Forge-Setup-x64.exe**: recommended installer ([direct download](https://github.com/Franc-dev/mitsumi-forge-releases/releases/latest/download/Mitsumi-Forge-Setup-x64.exe))
- **Mitsumi-Forge-x64.msi**: for managed installs

Requirements: Windows 10 or 11 (64-bit), 8 GB RAM. Docker Desktop is recommended for project sandboxes.

The installers aren't code-signed yet, so Windows SmartScreen may warn on first run ("More info", then "Run anyway"). Checksums are in each release's `SHA256SUMS.txt`.

Made by Mitsumi Distribution.
